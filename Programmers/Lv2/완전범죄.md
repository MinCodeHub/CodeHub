
처음 접근 시도 방법 : 그리디

그래서 정렬을 해야하나 생각했음

하지만 그렇게 하면 반례가 생김

so, 이 문제는 DP문제였음

DP문제는 모두 계산을 하기 때문에 정렬을 생각할 필요 없음


> dp[i][j] = i번째 물건까지 봤을 때 B를 j만큼 썼을 때의 A 최소값

dp[i-1][j]라는 하나의 상태에서 A 선택 / B 선택 두 가지 경우로 분기

```java
import java.util.*;

class Solution {
    static final int INF = 100000;
    public int solution(int[][] info, int n, int m) {
        int answer = 0;
        
        int size = info.length;
        int[][] dp = new int[size+1][m];
        //dp[i][j] = i번째 물건까지 봤을 때 B를 정확히 j만큼 사용했을 때의 A 최소값
        
        for(int i = 0; i<=size; i++){
            Arrays.fill(dp[i], INF);
        }
        
        dp[0][0] = 0;
        
        //i번째 물건 결정
        for(int i = 1; i<=size; i++){
            //현재 물건의 비용
            int a = info[i-1][0];
            int b = info[i-1][1];
        
            //이전까지 가능한 모든 B사용량 j를 하나씩 봄
            for(int j = 0; j<m; j++){ //이전까지의 모든 B사용량
                //a 선택
                dp[i][j] = Math.min(dp[i][j], dp[i-1][j]+a);
                
                //b 선택
                if(j+b<m){
                    dp[i][j+b] = Math.min(dp[i][j+b], dp[i-1][j]);
                }
            }
        }
        
        int min = INF;
        for(int j = 0; j<m ;j++){
            min = Math.min(dp[size][j], min);
        }
        
        
        return min >= n ? -1 : min;
    }
}
```
