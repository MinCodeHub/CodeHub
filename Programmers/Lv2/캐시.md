처음에는 HashMap만 생각했다가 순서는 그럼 어떻게 하지?에서 

LinkedList 생각했다가 

그럼 HashMap이 굳이 필요한가? 했다가 생각이 꼬여버림


푸는 방법이 여러가지 인 듯 하여 오늘은 LinkedList로 푸는 방식

내일은 LinkedHashMap 방식과 HashMap + LinkedList 방식으로 풀고 시간 복잡도 측정 예정
```java
import java.util.*;

class Solution {
    public int solution(int cacheSize, String[] cities) {
        LinkedList<String> cache = new LinkedList<>();
        int answer = 0;
        
        for(int i = 0; i<cities.length; i++){
            String city = cities[i].toLowerCase();
            
            if(cache.contains(city)){
                answer+=1;
                cache.remove(city);
                cache.addLast(city);
            }else{
                answer+=5;
                if(cacheSize>0){
                   if(cache.size() == cacheSize){
                     cache.removeFirst(); 
                } 
                    cache.addLast(city);
                }
                
            }
        }
        return answer;
    }
}
```
