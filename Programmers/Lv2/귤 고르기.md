역순으로 정렬을 해서 0부터 시작하고 싶었는데
역순 정렬 방식이 생각이 안났음

그래서 마지막인덱스부터 나열했고

k가 0보다 작아질 때까지 k에서 배열 값을 빼줬고
answer을 하나씩 더해 줌


HashMap으로 풀 수 있나? 생각 하다가 단순하게 풀었는데 
메모리 적으로 아쉬움


아쉬운 점 

1. int[] tmp = new int[10000001] 처럼 쓸데없이 큰 배열
2. Arrays.sort(tmp) 의미 없는 0 값이 대부분인데 전체 정렬 


```java

import java.util.*;

class Solution {
    public int solution(int k, int[] tangerine) {
        int answer = 0;
        int[] tmp = new int[10000001];
        
        for(int i = 0; i<tangerine.length; i++){
            int num = tangerine[i];
            tmp[num] +=1;
        }
        
        Arrays.sort(tmp);
          
        // for(int i = 10000000; i > 10000001 - tangerine.length; i--){
        //   System.out.print(tmp[i]+" ");
        // }
        
        int i = 0;
        while(k > 0){
            k -= tmp[10000000 - i];
            i++;
            answer++;
        }
         
        
        return answer;
    }
}
```


더 좋은 방법

HashMap + 정렬

귤 크기별 개수만 모아서
그 개수들만 정렬

```java
import java.util.*;

class Solution {
    public int solution(int k, int[] tangerine) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int t : tangerine) {
            map.put(t, map.getOrDefault(t, 0) + 1);
        }

        List<Integer> counts = new ArrayList<>(map.values());
        counts.sort(Collections.reverseOrder());

        int answer = 0;
        for (int c : counts) {
            k -= c;
            answer++;
            if (k <= 0) break;
        }

        return answer;
    }
}
```
